# Delivery Roadmap

## Phase 0 — Discovery (1 week)

- Confirm booking rules (minimum notice, cancellation window, max party size).
- Define operations workflow for hosts/managers.
- Decide notification channels (email, SMS, WhatsApp).

## Phase 1 — MVP Backend + Widget (3–5 weeks)

- Implement API endpoints from `openapi/reservation-api.yaml`.
- Build embeddable website widget.
- Add admin calendar/day list view.
- Add confirmation + reminder notification templates.

**Success criteria:**

- Customers can book online.
- Staff can confirm/manage reservations.
- No overbooking under concurrent requests.

## Phase 2 — Reliability + Insights (2–3 weeks)

- ✅ Add waitlist and auto-promote logic.
- ✅ Add no-show tracking.
- ✅ Add basic analytics dashboard (covers/day, cancellation rate).

## Phase 3 — Mobile App Enablement (3–6 weeks)

- Build staff mobile app (React Native/Flutter).
- Push notifications for new/cancelled reservations.
- In-app reservation status updates.

## Phase 4 — Growth Features

- Loyalty integration.
- Promotions and campaign-linked booking.
- Multi-restaurant support.
